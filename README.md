# 匯差口袋 · FX Pocket

Mobile-first manual exchange-rate calculator with currency conversion, buy/sell spread, product margin calculation, fees, and local history.

All calculations and history remain in your browser. No live exchange-rate feeds, accounts, analytics, or financial data uploads.

Open the website in Safari on iPhone → Share → Add to Home Screen.

The app uses relative asset paths and a service worker for offline caching. The source is static HTML/CSS/JavaScript; no build step is required.
